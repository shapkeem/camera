# 아이폰 룩 맞추기 (1차)

## 자료
- 아이폰: iPhone 12 Pro 셀카 1장 (HEIC, Display P3 → sRGB로 변환해서 비교)
- 플립7: Tune Camera 셀카 2장 (튜닝 끔 1장, 이전 추정 프리셋 1장). 같은 사람, 같은 방, 같은 옷이지만 **같은 순간의 쌍은 아님**
- 측정 영역: 얼굴 피부(YCbCr 피부 범위 + 중앙 영역), 셔츠(올리브 갈색), 벽(밝고 채도 낮은 픽셀)

## 측정 (0~255, Cb/Cr은 0 중심)
| 항목 | 플립7 원본 | 아이폰 | 이전 추정 프리셋 적용 | **새 프리셋 적용 (시뮬레이션)** |
|---|---|---|---|---|
| 피부 Y | 137.9 | 147.1 | 144.1 | **146.8** |
| 피부 Cb / Cr | −11.7 / 18.6 | −19.1 / 24.0 | −12.4 / 19.0 | **−19.1 / 23.5** |
| 피부 채도 | 22.4 | 31.0 | 23.0 | **30.7** |
| 피부 hue | 123.0° | 129.6° | 124.1° | **129.7°** |
| 셔츠 채도 | 10.6 | 16.4 | 10.9 | 14.7 |
| 벽 Cb / Cr | +1.0 / −2.7 (푸른 흰색) | −7.0 / +0.8 (아이보리) | −1.5 / +0.1 | **−6.3 / −0.2** |
| 얼굴 Y p10 / p90 | 108 / 160 | 110 / 177 | 110 / 168 | **108 / 175** |

## 결론
- 이 장면에서 아이폰은 플립7보다 **얼굴이 밝고, 대비가 크고, 따뜻하고(노란 쪽), 채도가 높다**.
- 처음 추정(채도 낮춤, 약한 따뜻함)은 **채도 방향이 반대**였다. 공개 자료만으로 정한 값의 한계.
- 따뜻함을 색온도처럼 파랑→노랑 축 위주로 바꿈 (Cb −1.0, Cr +0.4 비율). 아이폰 벽 색 이동(Cb −8, Cr +3.5)과 같은 방향.
- 채도를 올릴 때 피부 보호는 20%만 (아이폰 피부도 더 진했음). 내릴 때는 70% 유지.
- 새 프리셋: **밝기 +6%, 대비 +20%, 따뜻함 +12, 채도 +18%**. 피부와 벽은 아이폰과 거의 일치, 셔츠 채도와 가장 어두운 부분 깊이는 약간 부족.

## 한계
- 사진 1쌍, 실내 조명 1종, 장면도 완전히 같지 않음. 실외/낮/노란 조명에서는 다를 수 있음.
- 아이폰은 인물 마스크 기반 국소 처리를 한다(`apple-public-pipeline.md`). 여기서는 전역 처리만 한다.

# 2차: 스튜디오 비교 사진으로 다시 맞추기

## 자료
- GSMArena Photo Compare Tool (https://www.gsmarena.com/piccmp.php3) 의 무보정 원본 타일을 이어 붙여 사용 (분석용으로만 사용, 저장소에는 넣지 않음)
  - 같은 스튜디오, 같은 구도, 컬러체커 포함. 밝은 조명(idType=4)과 저조도(idType=5)
  - iPhone 12 Pro vs **Galaxy Z Flip5**, **Galaxy S24** (목록에 Flip7은 없음)
- SIFT + 호모그래피로 삼성 사진을 아이폰 구도에 정합 → 평평한 블록(12px, 표준편차 6 이하)의 평균색 쌍 약 1,800개씩 → CIELAB ΔE로 평가. 색이 있는 블록(채도 10 이상)은 가중치 5배

## 결과
| 룩 | 플립5 밝음 | 플립5 저조도 | S24 밝음 | S24 저조도 | 평균 |
|---|---|---|---|---|---|
| 보정 없음 | 4.51 | 6.21 | 5.83 | 10.04 | 6.65 |
| 1차 셀카 맞춤 (밝기 +6, 대비 +20, 따뜻함 +12, 채도 +18) | 9.66 | 5.36 | 7.93 | 6.48 | 7.36 |
| **따뜻함 +10, 채도 −10, 피부 +25** | 5.27 | 3.72 | 4.06 | 7.41 | **5.11** |

- 교차 검증(밝은 장면으로 맞추고 저조도로 시험, 플립5로 맞추고 S24로 시험): **따뜻함 +4~12, 채도 −10은 항상 같은 방향**. 밝기와 대비는 장면마다 부호가 바뀌어서 0으로 둠
- 17³ 3D LUT도 시도했지만, 학습에 쓰지 않은 쌍에서 보정 없음보다 나빠져서(과적합) 버림
- 1차 셀카 맞춤은 스튜디오에서 오히려 차이를 키웠다. 전체 채도를 올린 것이 원인

## 셀카와 스튜디오가 다른 이유
- 스튜디오(물건): 아이폰이 삼성보다 **덜 진하고 더 따뜻함**
- 셀카(사람): 아이폰 피부가 **더 밝고 더 진함**
- 애플이 공개한 인물/피부 별도 처리(`apple-public-pipeline.md`)와 맞는다 → **전체 색과 피부/얼굴을 분리**해서 처리
  - 피부 채도는 스튜디오 점수에 영향이 거의 없음 (5.10 → 5.11)

## 질감 (미세 디테일)
fine = 원본 − 가우시안(σ1), mid = 가우시안(σ1) − 가우시안(σ3), 비율 fine/mid:
| | 아이폰 12 Pro | 삼성 |
|---|---|---|
| 스튜디오 (플립5) | 0.83 / 0.73 | 1.04 / 0.99 |
| 사용자 사진 (플립7, 같은 장면) | 0.70~1.29 | 1.51~2.14 |

- 플립7은 미세 디테일(샤픈)이 아이폰의 1.5~2배. 가장 미세한 대역을 40% 줄이면 셀카 비율이 1.49 → 1.04 (아이폰 1.08)

## 최종 "아이폰 느낌" (3차)
| 항목 | 값 | 근거 |
|---|---|---|
| 밝기 / 대비 | 0 / 0 | 장면마다 방향이 달라 일관성 없음 |
| 따뜻함 | +10 | 스튜디오 교차 검증 + 셀카 벽 색 |
| 채도 (피부 외) | −10% | 스튜디오 교차 검증 |
| 피부 채도 | +35% | 셀카 피부 Cb/Cr |
| 질감 | 미세 대역 −40% | fine/mid 비율 |
| 얼굴 밝게 | 얼굴 중심 평균 140까지, 최대 ×1.15 | 셀카 피부 Y 138 → 146 (아이폰 147) |
| 얼굴 우선 노출 | 켬 (HAL 얼굴 인식 + FACE_PRIORITY, 일반 모드만) | 아이폰 동작 방식 |

시뮬레이션 (플립7 셀카 → 아이폰 셀카 목표): 피부 Y/Cb/Cr 137.9/−11.7/18.6 → **146.1/−17.2/22.6** (아이폰 147.1/−19.1/24.0)

## 한계
- 스튜디오 비교는 Flip7이 아니라 Flip5/S24. 같은 삼성 계열이지만 ISP 세대가 다름
- 피부 판정은 색 기반이라 베이지 물건, 나무에도 일부 적용됨
- 얼굴 밝히기는 ML Kit 얼굴 상자(사각형) 기반 타원 마스크. 머리카락이나 목 경계는 정확하지 않음
